## 项目简介
本项目为平衡车（倒立摆）的核心控制程序，基于 **三环控制（角度+速度+转向）** 算法实现车辆的静止直立与动态平衡。  
对应本地工程目录：`04-三环控制`

## 硬件与开发环境
- **开发环境**：Keil µVision5（工程文件：`Project.uvprojx`）
- **主控单元**：常见平衡车 STM32 系列开发板
- **核心外设**：
  - 编码器（Encoder）：获取电机转速与位移
  - PWM：电机驱动控制
  - I2C/MPU6050：姿态传感器（陀螺仪+加速度计）
  - 定时器（Timer）：控制周期与中断
  - 按键与 OLED：调试与状态指示（第一个表示开始电机运作，第二个表示停止电机运作）
  - 电机：JGA25-370
  - 蓝牙hc-04

## 软件架构
工程目录结构如下：
- `Start/`：启动文件与内核头文件
- `Library/`：STM32 标准库/外设驱动
- `Hardware/`：板级外设驱动（编码器、PWM、I2C、LED、按键等）
- `System/`：系统配置与定时器
- `User/`：核心业务逻辑与控制算法
  - `main.c`：主循环与任务调度
  - `PID.c / PID.h`：三环 PID 控制算法实现
- `Objects/`、`Listings/`、`DebugConfig/`：Keil 编译生成文件（已忽略）

## 三环控制原理
平衡车稳定依赖三个闭环控制：
1. **角度环（内环）**：保证车身物理直立，快速响应倾角变化。
2. **速度环（中环）**：维持车身整体速度，通过积分消除位置漂移。
3. **转向环（外环）**：控制车身转向与偏航，保持直线行驶或指定转角。
4. 个人建议：转向环可以试着加一下陀螺仪绕z轴的积分，不过要注意0飘问题，因为可能材料原因手动把他转一下或者由于地形原因，
就算他转向了但是他的轮子实际并没有转够对应的角度而导致偏移，所以建议融合一下z轴的转向积分好些。

> 核心参数与调参记录主要在 `User/PID.c` 中实现。

## 编译与烧录
1. 使用 Keil 打开 `Project.uvprojx`
2. 执行 `Build` 编译（建议清理 `Objects` 等临时文件后全编译）
3. 通过 ST-Link/J-Link 烧录至主控
4. 上电后车辆进入直立控制状态

注意：由于电机的减速比较小，静止的时候会止不住的抖动属于正常现象。
mpu6050的配置：获取mpu6050的数据不要经过其寄存器內部滤波，否则会导致响应过慢，无法直立。
